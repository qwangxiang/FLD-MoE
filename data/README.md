# 陕西数据

`shaanxi.csv` 从原研究项目的 `Data/Data_ShaanXi_20250101_20260430.csv` 按字节复制，未重采样、插值、删列或预先标准化。文件使用带 BOM 的 UTF-8 编码，共 46,560 行观测，覆盖 485 个完整自然日。

| 列 | 内容 |
| --- | --- |
| `时间` | 中国本地时间，15 分钟间隔，无时区后缀 |
| `日前电价(元/MWh)` | 目标电价，元/MWh |
| 8 个 `预测(MW)` 列 | 新能源、风电、光伏、负荷、联络线、发电总出力、非市场机组出力、水电 |
| `2米气温_01` 至 `_04` | 四个节点的气温 |
| `2米露点温度_01` 至 `_04` | 四个节点的露点温度 |
| `100米风速_01` 至 `_04` | 四个节点的风速 |
| `短波总辐射_01` 至 `_04` | 四个节点的短波辐射 |

气象列保持原表数值和口径，未添加未核实的单位或站点名称。运行时严格校验列顺序、有限值、完整自然日、15 分钟连续性及价格边界，不静默填补或排序异常数据。

训练、验证和测试的日期范围见根目录 README；每次运行会在 `run.json` 中记录数据内容的 SHA256。
